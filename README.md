# zotiquestgames.com

The home site of Zotiquest Games: a hub that points to the Loner and Ensemble
sites, the latest releases, the free SRDs, Loner Assistant and the newsletter.

- Plain HTML and CSS, no build step. Published by GitHub Pages from `main`.
- Custom domain in `CNAME` (`zotiquestgames.com`).
- Every push to `main` goes live: work on a branch and open a pull request.
- Content comes from the Zotiquest catalog (`zotiquestgames/catalog`,
  `sites/zotiquestgames.yml`). The "New releases" section lists the four most
  recent released titles, with store links from their catalog ids.

## Fonts

Inter and Rubik Glitch, both under the SIL Open Font License 1.1 (see
`assets/fonts/OFL-*.txt`), subset to Latin and converted to WOFF2.
